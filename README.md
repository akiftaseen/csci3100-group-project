# The Jade Trail UI Demo

A presentation-ready Next.js demo of The Jade Trail marketplace and messaging
interface. The project is intentionally frontend-only: listings, conversations,
and the default `jade.explorer` profile are supplied by local demo data.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and use **One-click login**.
No environment variables, database, object storage, or account setup are
required.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production build
- `npm run typecheck` — validate the TypeScript project

## Demo scope

The interface supports local presentation interactions such as filtering
listings, opening item details, browsing conversations, and sending in-memory
text messages. Data resets when the development server or browser session is
restarted.
